# PCL Linking (`v 1.1.3`)

**PCL Linking**是基于 **龙腾猫跃 (LTCat)** 开源的 **Plain Craft Launcher (PCL) 2.14.0.0** 进行二次开发的非盈利 Minecraft 多人联机与实用工具增强分支。

- **原作者与上游项目**：龙腾猫跃 (LTCat) — Meloong-Git/PCL
- **赞助原作者 PCL**：[爱发电 · 龙腾猫跃](https://meloong.com/afd/a/LTCat)
- **分发许可与文档**：[LICENCE](LICENCE) · [LICENSE-MIT](LICENSE-MIT) · [PRIVACY.md](PRIVACY.md) · [THIRD-PARTY-LICENSES.md](THIRD-PARTY-LICENSES.md)

> 日常稳定单人游玩建议优先使用官方原版 PCL；**PCL Linking** 聚焦免管理员权限 EasyTier 多人组网、端到端加密好友/群聊与本地开服运维增强。

## 核心功能模块（`v 1.1.3`）

### 多人联机与社交增强

- **EasyTier 增强组网、虚网直传与进房核对**：支持用户态 `--no-tun` 免管理员权限联机、节点并发测速择优、30 秒实时延迟折线图与抖动统计、成员进出提示、局域网广播带出房主昵称、一键写入 `servers.dat` 与一键连通性自检报告；同时提供**扫描局域网存档建房**、**剪贴板一键进房 & 整段识别**、**固定车队房间码**、**语音/地图多端口穿透**（如 `24454`）及**断线 3 秒自动重连（最多 3 次）**。加入房间后内置经由 EasyTier 虚网的 **HMAC-SHA256 + AES-256-CBC 加密侧通道**：自动静默核对房主 Mod 一致性（不一致才弹补齐向导），并支持**点对点大文件 / 世界存档接力直传**（自动跳过 `session.lock` 并做 SHA-256 与 ZipSlip 校验）。首次使用时程序会按本机架构自动从 EasyTier 官方 GitHub Releases (`v2.6.4`) 下载并执行 **SHA-256** 校验，无需单独捆绑二进制文件。
- **好友私聊 & 无服务器加密群聊**：单窗一键添加好友（剪贴板名片自动识别）并静默双向握手验密；采用 `lml-v2-` / `lml-grp-v2-` 域分离密钥派生（独立加密密钥与 HMAC 鉴权密钥 + 固定时间校验），**需聊天双方均更新至 `v 1.0.1+` 才能互通**；支持 `G` 开头独立密钥加密群聊（建群 / 加群 / 群名片 / 拉好友入群）、2000 字消息、`Shift+Enter` 换行、切换会话即时拉取及失败消息一键重发。
- **端到端加密文件与截图传输**：支持点击「文件」、拖入聊天窗口或 `Ctrl+V` 粘贴截图，经 AES-256 + SHA-256 加密上传中继并解密保存（单文件上限 **10 MB**）。
- **好友实例自动同步（发布 / 订阅）**：可将指定实例设为主同步源，推送 Mod 清单与可选加密 `config` 包（≤ 8 MB，内置 ZipSlip 与解压体积防护，覆盖前自动保留最近 3 份本地备份）；接收方绑定本地实例后，每次启动自动检测并同步最新修订版（也支持随时手动同步）。
- **高清游戏内浮层 & 无边框全屏**：支持在浮层与快捷键间切换好友/群聊、实时查看游戏内存/时长，以及一键切换 **Win32 无边框全屏**。

### 正版验证、多源资源与数据包安装

- **正版微软登录与官方 PCL 协同验证**：支持标准设备码微软 OAuth 验证与离线/外置登录；未配置自主 Client ID 时也可协同本地官方 PCL 完成正版验证与皮肤管理。
- **多平台资源下载与存档直装**：接入 Modrinth、CurseForge、**Hangar (PaperMC)** 与 **SpigotMC**（插件），新增**地图下载**与 **Planet Minecraft** 外链检索（地图一键解压入 `saves\`）；**数据包**支持直接选定当前实例下的世界存档一键装入 `saves\<存档>\datapacks\`。

### 本地开服与状态探测

- **多核心本地开服管理与性能调优**：支持多服务端档案管理（Vanilla / Paper / Purpur / Fabric / NeoForge / Forge）、参数与控制台 OP/白名单联动、一键共享到联机房间、崩溃自动重启、后台共享定时多维度世界备份、插件/Mod 下载及客户端 ↔ 服务端 Mod 互转；内置**已安装插件管理**（识别前置缺失、启停删及 Modrinth + Hangar 一键检查更新）与**性能预设 / Aikar's Flags / Generational ZGC 面板**（可视调节视距、模拟距离、Paper 区块与实体上限）。
- **Minecraft 服务器状态探测 (`SLP 1.7+`)**：纯 TCP 实时探测 RTT 延迟、服务端版本、在线人数与 MOTD，支持 IPv4 / IPv6、关注列表巡检、写入 `servers.dat` 与直连启动。

### 实例管理与排雷工具

- 集成实例场景模式一键切换（单人画质向 / 多人高帧联机向 / 自定义预设）、按实例游玩时长统计与全局排行榜、退出检测到存档变动自动快照备份、**启动前 Mod 静态冲突与依赖体检**（过滤非阻塞「声明冲突」误报，并可在「设置 → 启动」自由开关 6 类报错提醒项）、实时游戏日志高亮与智能诊断、**跨实例 `options.txt` 键位/画面/音频选择性迁移与按键冲突一键解绑**、实例对比 (Diff) 与一键瘦身清理，以及世界存档、实例快照、资源包合并与材质光影更新工具。

### 百宝箱、帮助中心与便携存储

- **统一「百宝箱」与内置帮助**：整合原「工具」与 PCL「百宝箱 / 更多」栏，提供**清理垃圾、今日人品、创建桌面快捷方式、自定义链接下载、Minecraft 成就图标生成、3D 皮肤预览与头像导出 (`64×64`~`128×128`)、多资源包无冲突合并、全局快捷键、本地开服与服务器状态探测**，并在侧边栏内置「**使用帮助**」与「**反馈与日志**」快捷入口；所有设置与「关于」页动态读取全局 `VersionDisplay`，配置优先便携存储于程序同级 `PCL Linking\` 目录（凭据经 Windows DPAPI 加密），可与官方 PCL 和平共存。
- **合规主题约束**：遵循原版《PCL 分发有限许可》，界面主题固定使用 PCL 经典蓝色系（保留浅色 / 深色 / 跟随系统及自定义背景图片）。

## 编译说明

- **环境要求**：Visual Studio 2022+（「.NET 桌面开发」工作负载 / MSBuild）与 .NET Framework 4.8 Targeting Pack。
- **构建命令**：在仓库根目录执行 `build.cmd`（或设置 `set CI=1` 后运行 `build.cmd __child`），生成产物位于 `dist\PCLLK.exe` 并自动复制一份到当前用户桌面。
- **版本更新与多语言**：支持在「设置 → 个性化」切换 **简体中文 / English** 双语界面（即时生效），并在「设置 → 关于」按需检查 GitHub Releases 最新正式版本。
